# NOWFLIX 키오스크 설치 가이드

병원에서 태블릿에 NOWFLIX 앱을 설치하고 키오스크(화면 잠금) 상태로 만드는 방법입니다.
**개발 지식이 없어도** 순서대로 따라 하면 됩니다. 기준은 **윈도우 PC**입니다.

> 준비물: 윈도우 PC 1대 · USB 케이블(데이터 전송용) · 태블릿 5대 ·
> 전달받은 폴더(그 안에 `dist\nowflix-1.1.0.apk` 와 `scripts\install.sh` 가 있습니다)

---

## 0. 왜 이런 과정이 필요한가 (30초 요약)

이 앱은 태블릿을 **한 가지 화면에만 갇히게** 만드는 키오스크 앱입니다.
그래서 일반 앱처럼 스토어에서 설치할 수 없고, PC와 USB로 연결해
**adb** 라는 도구로 설치·잠금을 해줘야 합니다. 한 번만 세팅하면 그 뒤로는
전원만 켜면 자동으로 NOWFLIX가 실행됩니다.

---

## 1. PC에 adb(안드로이드 플랫폼툴) 설치하기 — 윈도우

1. 웹브라우저에서 아래 주소를 엽니다.
   `https://developer.android.com/tools/releases/platform-tools`
2. **"Download SDK Platform-Tools for Windows"** 를 눌러 zip 파일을 받습니다.
3. 받은 zip 파일을 마우스 오른쪽 → **"압축 풀기"** 합니다.
   압축을 풀면 `platform-tools` 폴더가 생깁니다. 이 폴더를 `C:\platform-tools` 로 옮겨 둡니다.
4. 잘 설치됐는지 확인합니다.
   - 윈도우 검색창에 **cmd** 를 입력해 **명령 프롬프트**를 엽니다.
   - 아래를 입력하고 Enter:
     ```
     cd C:\platform-tools
     adb version
     ```
   - `Android Debug Bridge version ...` 이 나오면 성공입니다.

> 💡 앞으로 나오는 명령은 모두 이 `C:\platform-tools` 폴더 안에서 실행합니다.
> 전달받은 폴더도 이 근처(예: `C:\nowflix`)에 두면 편합니다.

---

## 2. 태블릿에서 개발자 옵션 · USB 디버깅 켜기

태블릿마다 메뉴 이름이 조금 다를 수 있지만 순서는 같습니다.

1. 태블릿 **설정 → 태블릿 정보(휴대전화 정보)** 로 들어갑니다.
2. **"빌드번호"** 를 찾아 **7번 연속** 빠르게 탭합니다.
   → "개발자가 되었습니다" 라는 안내가 뜹니다.
3. **설정 → 시스템 → 개발자 옵션** 으로 들어갑니다.
   (삼성은 설정 맨 아래에 "개발자 옵션" 이 새로 생깁니다.)
4. **"USB 디버깅"** 을 켭니다.
5. PC와 태블릿을 USB 케이블로 연결합니다.
   태블릿 화면에 **"USB 디버깅을 허용하시겠습니까?"** 창이 뜨면
   **"이 컴퓨터에서 항상 허용"** 을 체크하고 **확인**을 누릅니다.

연결이 잘 됐는지 확인:
```
adb devices
```
목록에 태블릿이 `device` 상태로 한 줄 나오면 준비 완료입니다.
`unauthorized` 로 나오면 4~5번(디버깅 허용)을 다시 확인하세요.

---

## 3. ⚠️ 가장 중요 — 태블릿에서 모든 계정을 뺀다

이 키오스크는 **"device owner"** 라는 강력한 권한이 필요합니다.
그런데 **태블릿에 계정(구글 계정 등)이 하나라도 등록돼 있으면 이 권한 설정이 실패**합니다.

- 태블릿 **설정 → 계정** 으로 들어가 **구글 계정을 포함한 모든 계정을 삭제**합니다.
- 삼성 계정, 기타 계정도 전부 뺍니다.
- 계정을 뺀 뒤 설치를 진행하고, 설치가 끝난 뒤에도 계정을 다시 추가하지 마세요.

> 실수로 계정이 남은 채 설치를 시도하면 4단계에서 "계정 때문에 실패" 라는 안내가 나옵니다.
> 그때는 계정을 빼고 설치 스크립트를 다시 실행하면 됩니다.

---

## 4. install.sh 로 설치하기

설치 스크립트가 **연결 확인 → 기존 앱 정리 → 설치 → 잠금 설정 → 실행 → 결과 확인**
까지 한 번에 처리합니다. 실패하면 무엇이 문제인지 한국어로 알려줍니다.

윈도우에서는 **Git Bash** 로 실행하는 것이 가장 쉽습니다.

1. `https://git-scm.com/download/win` 에서 Git 을 받아 설치합니다(기본값으로 계속 다음).
   설치하면 **Git Bash** 가 함께 깔립니다.
2. 전달받은 폴더(예: `C:\nowflix`)에서 마우스 오른쪽 → **"Git Bash Here"**.
3. 아래를 입력하고 Enter:
   ```
   ./scripts/install.sh
   ```
4. 태블릿이 여러 대 연결돼 있으면 **어느 태블릿에 설치할지 번호로 고르는** 화면이 나옵니다.
   한 대씩 연결해 두면 자동으로 그 한 대에 설치됩니다.

### 성공하면 이렇게 보입니다
```
────────────────────────────
6) 설치 결과 확인
────────────────────────────

  ✅ device owner: 지정됨
  ✅ 화면 고정(lock task): 켜짐 (LOCKED)

  🎉 설치 성공!  이 태블릿은 이제 NOWFLIX 키오스크로 잠겼습니다.
     • 홈/최근앱 버튼과 상태바가 막혀 앱을 벗어날 수 없습니다.
     • 관리자 진입: 화면 오른쪽 위 모서리를 3초간 길게 누른 뒤 PIN 입력
     • 기본 PIN: 739104
```
태블릿 화면에 NOWFLIX 메인(빨간 띠 + 포스터들)이 떠 있으면 그 태블릿은 끝난 것입니다.

---

## 5. 태블릿 5대를 순서대로 처리하기

가장 헷갈리지 않는 방법은 **한 대씩** 처리하는 것입니다.

1. 태블릿 ①을 USB로 연결 → (2단계 USB 디버깅 허용, 3단계 계정 제거) → `./scripts/install.sh` 실행 → "설치 성공" 확인.
2. 태블릿 ①의 USB를 뽑고, 태블릿 ②를 연결 → 같은 과정 반복.
3. ③ ④ ⑤ 도 같은 방식으로.

각 태블릿마다 **2단계(USB 디버깅)와 3단계(계정 제거)** 는 처음 한 번씩 꼭 해야 합니다.
5대를 동시에 연결해도 되지만, 그 경우 스크립트가 매번 번호를 물어보므로
익숙하지 않다면 **한 대씩** 하는 것을 권합니다.

> 나중에 앱을 새 버전으로 바꿀 때도 이 스크립트를 그대로 다시 실행하면 됩니다.
> (이 앱은 항상 `adb install -t` 로 설치·업데이트됩니다. 스크립트가 알아서 처리합니다.)

## 6. 이미 설치된 태블릿을 새 버전으로 업데이트하기

앱만 새 버전으로 바꾸는 절차입니다(예: **v1.0.0 → v1.1.0**).
**처음 설치와 다릅니다.** 앱을 지우지 않고 **덮어쓰기**만 하므로
계정 제거·device owner 지정·잠금 설정을 **다시 할 필요가 없고**, 태블릿 설정도 그대로 남습니다.

### ⚠️ 0단계 — Git Bash 를 열면 **이 줄을 먼저** 입력하세요

```
export PATH=$PATH:/c/platform-tools
```

Git Bash 는 윈도우 명령 프롬프트와 달리 `C:\platform-tools` 를 자동으로 찾지 못합니다.
이 줄을 입력하지 않으면 다음 단계에서 이런 오류가 납니다.

```
bash: adb: command not found
```

- 이 설정은 **창을 닫으면 사라집니다.** Git Bash 를 새로 열 때마다 다시 입력하세요.
- 입력했는지 확인하려면 `adb version` → `Android Debug Bridge version ...` 이 나오면 됩니다.
- platform-tools 를 다른 곳에 두었다면 그 경로로 바꿔 쓰세요.
  예) `D:\tools\platform-tools` → `export PATH=$PATH:/d/tools/platform-tools`
  (윈도우의 `C:\` 는 Git Bash 에서 `/c/` 로 씁니다.)

### 1단계 — 새 패키지 준비

전달받은 `nowflix-install-package.zip` 의 압축을 풀고, 그 `nowflix` 폴더에서
마우스 오른쪽 → **"Git Bash Here"**.
`dist/nowflix-1.1.0.apk` 파일이 들어 있는지 확인합니다.

### 2단계 — 태블릿 연결 확인

태블릿을 USB로 연결한 뒤:

```
adb devices
```

`device` 로 보이면 정상입니다.
`unauthorized` 면 태블릿 화면의 "USB 디버깅 허용" 창에서 **항상 허용**을 체크하세요.

### 3단계 — 덮어쓰기 설치

```
adb install -r -t dist/nowflix-1.1.0.apk
```

`Success` 가 나오면 끝입니다.
(`-r` = 기존 앱 위에 덮어쓰기, `-t` = 이 앱은 testOnly 라 항상 필요합니다.)

### 4단계 — 앱 다시 시작

```
adb shell am force-stop kr.prism.nowflix
adb shell am start -n kr.prism.nowflix/.MainActivity
```

태블릿에 NOWFLIX 메인 화면(빨간 띠 + 포스터)이 다시 뜨면 완료입니다.

### 5단계 — 버전 확인

태블릿에서 **오른쪽 위 모서리를 3초간 길게** 누르고 **PIN** 을 입력해 관리자 화면을 엽니다.
**앱 버전**이 **1.1.0** 으로 보이면 업데이트가 제대로 된 것입니다.

태블릿 5대 모두에 대해 2~5단계를 반복합니다.
(0단계는 Git Bash 창을 새로 열 때만 다시 입력하면 됩니다.)

### 업데이트가 안 될 때

| 화면에 나온 말 | 뜻 / 해결 |
|---|---|
| `bash: adb: command not found` | **0단계를 건너뛴 것입니다.** `export PATH=$PATH:/c/platform-tools` 를 입력하고 다시 시도 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 서명이 다른 APK 입니다. **덮어쓰기 불가** — 담당 개발자에게 연락하세요 (임의로 앱을 지우면 잠금 설정을 처음부터 다시 해야 합니다) |
| `INSTALL_FAILED_TEST_ONLY` | `-t` 를 빠뜨렸습니다. `adb install -r -t ...` 로 다시 |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 이미 더 높은 버전이 깔려 있습니다. 업데이트가 필요 없습니다 |
| `no devices/emulators found` | 케이블이 충전 전용이거나 USB 디버깅이 꺼져 있습니다. 2단계 확인 |

> 앱을 **완전히 새로 깔아야 할 때만** `./scripts/install.sh` 를 씁니다.
> 이 스크립트는 기존 앱을 지우고 다시 설치하므로 **계정 제거·device owner 지정을 다시 하게 됩니다.**

## 7. 실패했을 때 확인할 것 세 가지

설치 마지막에 "성공"이 안 뜨면 아래 **세 가지**를 순서대로 확인하세요.

1. **태블릿에 계정이 남아 있지 않은가?**
   → 설정 → 계정에서 모든 계정 삭제 후 `./scripts/install.sh` 재실행.
   (device owner 실패의 90%는 이것 때문입니다.)

2. **USB 연결/디버깅이 살아 있는가?**
   → Git Bash에서 `adb devices` 실행. 태블릿이 `device` 로 보여야 합니다.
   `unauthorized` 면 태블릿 화면의 디버깅 허용 창을 다시 확인, 안 보이면 케이블을 뺐다 꽂기.
   충전만 되는 케이블이면 **데이터 전송용 케이블**로 바꾸세요.

3. **그래도 안 되면 태블릿을 재부팅한 뒤 다시 시도.**
   → 재부팅 후 3단계(계정 제거)부터 다시 확인하고 스크립트를 재실행합니다.
   완전히 초기화하고 싶으면 `./scripts/uninstall.sh` 로 깨끗이 지운 뒤 다시 설치하세요.

그래도 해결되지 않으면 `docs/인계문서.md` 의 문제 해결 순서를 따르거나 담당 개발자에게 연락하세요.

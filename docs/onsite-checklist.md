# NOWFLIX 키오스크 — 설치 당일 현장 점검표

병원에 태블릿을 설치하는 당일, 태블릿 **앞에서 순서대로** 확인하는 목록입니다.
개발 지식이 없어도 그대로 따라 하실 수 있게 "무엇을 누르고 → 무엇이 보여야 하는지"까지 적었습니다.

- ✅ 표시가 **정상**입니다. 하나라도 안 되면 그 줄의 〔안 될 때〕를 확인하세요.
- 🖥️ = 에뮬레이터(자동 검증, GitHub Actions)에서 이미 확인된 항목입니다. 현장에서는 재확인만 하면 됩니다.
- 📱 = **실기기에서만 확인 가능**한 항목입니다. 특히 삼성 One UI 고유 동작이라 자동 검증이 불가능합니다. 반드시 현장에서 직접 확인하세요.

준비물: 설치할 태블릿, Wi‑Fi 비밀번호, 관리자 PIN(기본 `000000`), 관리자 웹 주소(https://nowflix-admin.vercel.app), 관리자 폰 1대.

---

## 0. 설치 전 준비 (기기 담당자)

- [ ] 📱 태블릿을 **공장초기화**한 뒤, 구글 계정을 **등록하지 않은 상태**로 첫 화면까지만 진행한다.
      → device owner(완전 잠금)를 걸려면 계정이 하나도 없어야 합니다. 계정이 있으면 완전 잠금이 안 걸리고 "차선책 모드"로만 동작합니다.
- [ ] 📱 Wi‑Fi에 연결한다. **설정 → Wi‑Fi**에서 연결 확인(상단에 Wi‑Fi 아이콘).
- [ ] 📱 **개발자 옵션 → USB 디버깅**을 켠다. (설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 뒤로 → 개발자 옵션)
- [ ] 앱 설치와 완전 잠금 설정은 `docs/kiosk-recovery.md`의 명령을 그대로 사용한다(담당자용).

## 1. 첫 실행 & 메인 화면

- [ ] 🖥️ 앱을 실행하면 **가로 화면**으로 뜬다. 세로로 눕혀도 화면은 가로를 유지한다.
- [ ] 🖥️ 상단에 **빨간 띠**가 있고 왼쪽에 **NOWFLIX** 로고, 오른쪽에 **QR 코드**가 보인다.
- [ ] 🖥️ 빨간 "TOP N" 칩과 "오늘 대한민국의 TOP N 콘텐츠" 문구가 보인다. (N = 등록된 파트 수)
- [ ] 🖥️ 콘텐츠 **카드가 파트 수만큼** 가로로 나열된다. (6개면 화면에 꽉 차고, 7개 이상이면 좌우로 스크롤됨)
- [ ] 📱 카드 썸네일 이미지가 정상적으로 보인다. (인터넷이 연결돼 있어야 원격 썸네일이 뜸. 안 뜨면 기본 이미지로 대체됨)

〔안 될 때〕화면이 검고 카드가 없으면 인터넷 연결을 확인하세요. 그래도 안 되면 앱을 완전히 종료 후 재실행.

## 2. 영상 목록 화면 (카드 → 목록)

- [ ] 🖥️ 아무 **카드나 한 번 누른다** → 해당 파트의 **영상 목록 화면**으로 넘어간다.
- [ ] 🖥️ 왼쪽에 파트 포스터·제목·"재생목록 · 동영상 N개"·"▶ 모두 재생"·"메인으로"가 보인다.
- [ ] 🖥️ 오른쪽에 영상들이 **순번·썸네일(시간 배지)·제목·조회수/게시일** 형태로 나열된다.
- [ ] 📱 영상 썸네일 이미지가 실제로 로드된다. (인터넷 필요)
- [ ] 🖥️ 왼쪽 **"메인으로"를 누른다** → 다시 메인 화면으로 돌아온다.

〔안 될 때〕"잠시 후 다시 시도해주세요"만 보이면 인터넷/유튜브 접근을 확인. 잠시 뒤 자동으로 다시 시도됩니다.

## 3. 재생 화면 (목록 → 재생)

- [ ] 📱 목록에서 영상을 **하나 누르거나 "▶ 모두 재생"을 누른다** → 재생 화면으로 넘어가고 **영상이 자동 재생**된다. (실제 유튜브 재생은 실기기 인터넷에서만 확인 가능)
- [ ] 🖥️ 화면을 한 번 터치하면 **재생/일시정지 버튼, 진행 바, 시간, "다음 영상"**이 나타난다.
- [ ] 🖥️ 약 3초간 손대지 않으면 컨트롤이 **스르륵 사라진다**. 왼쪽 위 "← 목록으로"는 계속 남아 있다.
- [ ] 📱 **영상 위 아무 곳이나 여러 번 눌러 본다** → 유튜브 로고, 영상 제목, "Watch on YouTube", 추천 영상 같은 **유튜브 자체 UI가 절대 눌리지 않는다**. (우리 컨트롤만 나타남 = 정상)
      → 이 "터치 차단막"이 핵심입니다. 만약 유튜브 페이지로 빠져나가면 즉시 담당자에게 알리세요.
- [ ] 🖥️ "← 목록으로"를 누르면 영상 목록으로 돌아온다.

## 4. 자동 복귀 (무인 운영)

- [ ] 🖥️ 메인/목록 화면에서 **아무 것도 누르지 않고 기다린다** → 설정된 복귀 시간(기본 120초) 뒤 **자동으로 메인 화면**으로 돌아온다.
- [ ] 📱 실제 대기 시간(예: 2분)을 재서 복귀되는지 초시계로 한 번 확인한다.

## 5. 관리자 진입 (숨은 제스처 → PIN)

- [ ] 🖥️ **화면 오른쪽 위 모서리를 손가락으로 3초간 꾹 누른다** → **관리자 PIN 입력** 화면이 뜬다.
      (메인·목록·재생 어느 화면에서든 동작해야 합니다. 재생 화면에서도 되는지 꼭 확인.)
- [ ] 🖥️ **틀린 PIN을 5번** 넣으면 "잠시 후 다시 시도해주세요"와 함께 **30초간 잠긴다**. (30초 뒤 자동 해제)
- [ ] 🖥️ **맞는 PIN**(기본 `000000`)을 넣으면 **관리자 화면**이 뜬다.
- [ ] 🖥️ 관리자 화면에 복귀 시간·파트 수·잠금 모드·앱 버전·마지막 원격 설정 수신 시각이 보인다.
- [ ] 🖥️ 오른쪽 **QR 코드**를 관리자 폰으로 스캔하면 관리자 웹이 열린다.

〔중요〕설치가 끝나면 기본 PIN `000000`을 **관리자 웹에서 반드시 새 PIN으로 변경**하세요.

## 6. 키오스크 잠금 (완전 잠금 = device owner)

> 아래 (1)~(4)는 에뮬레이터에서 자동 검증(🖥️)되었지만, **삼성 실기기에서는 One UI 동작이 달라** 반드시 재확인(📱)해야 합니다.

- [ ] 🖥️📱 관리자 화면의 **잠금 모드**가 "완전 잠금 (device owner)"로 표시된다.
      → "차선책 (화면 고정 + 홈 런처)"로 나오면 device owner가 안 걸린 것. 0번(계정 없이 초기화)부터 다시.
- [ ] 📱 **홈 버튼**을 눌러도 앱을 벗어나지 못한다.
- [ ] 📱 **최근 앱(멀티태스킹) 버튼**을 눌러도 앱을 벗어나지 못한다.
- [ ] 📱 **뒤로 가기**를 눌러도 앱이 종료되지 않는다.
- [ ] 📱 화면 상단을 **아래로 쓸어내려도** 알림창(상태바 그림자)이 내려오지 않는다.
- [ ] 📱 화면을 껐다 켜도(전원 버튼) **잠금화면 없이** 바로 키오스크로 돌아온다.
- [ ] 📱 **태블릿을 재부팅**한 뒤 자동으로 키오스크 앱이 다시 실행된다.

## 7. 삼성 One UI 고유 동작 (📱 실기기 전용, 특히 주의)

자동 검증(에뮬레이터)으로는 확인할 수 없는, 삼성 태블릿만의 기능들입니다. **하나라도 앱을 빠져나가게 만들면** 설정에서 꺼야 합니다.

- [ ] 📱 **엣지 패널**(화면 오른쪽 가장자리의 반투명 손잡이)을 안쪽으로 쓸어본다 → 앱을 벗어나면
      **설정 → 디스플레이 → 엣지 패널 → 끔**.
- [ ] 📱 **빅스비 키 / 측면 버튼 길게 누르기** → 빅스비나 다른 앱이 뜨면
      **설정 → 유용한 기능 → 측면 버튼** 동작을 확인/변경.
- [ ] 📱 **절전 모드 / 적응형 절전**으로 화면이 어두워지거나 앱이 종료되지 않는지 확인 →
      **설정 → 배터리 → 절전 모드 끔**, 그리고 이 앱을 **절전 예외(제한 없음)**로 등록.
- [ ] 📱 **화면 자동 꺼짐 시간**을 **최대(또는 없음)**로 설정. (설정 → 디스플레이 → 화면 자동 꺼짐)
      → 앱이 화면을 계속 켜두지만, 시스템 설정도 함께 넉넉히 잡아두면 안전합니다.
- [ ] 📱 **밝기 자동 조절**을 끄고 밝기를 충분히 높게 고정.
- [ ] 📱 **소프트웨어 자동 업데이트**로 인한 재부팅 시간대를 야간으로 지정하거나 꺼둔다.
- [ ] 📱 **화면 회전 잠금**은 신경 쓰지 않아도 됨(앱이 가로로 고정). 다만 물리적으로 가로 거치되었는지 확인.

## 8. 안전장치 — 인계 전 "완전 해제" 리허설 (반드시)

병원에 넘기기 전에, **잠금을 풀 수 있는지**를 한 번 직접 해봐야 합니다. (공장초기화 없이 평범한 태블릿으로 되돌아가는지)

- [ ] 🖥️ 방법 A(앱 내부): 관리자 화면 → **"키오스크 모드 완전 해제"** → 확인 → 앱이 종료되고
      홈 버튼이 다시 동작하는지 확인. (device owner 권한과 홈 런처 설정이 풀립니다)
- [ ] 🖥️ 방법 B(비상, PC 필요): 앱이 멈춰도 PC에서 `adb shell dpm remove-active-admin kr.prism.nowflix/.kiosk.KioskAdminReceiver`
      로 **공장초기화 없이** 잠금 해제 가능. (앱이 `testOnly`라 가능 — 자세한 명령은 `docs/kiosk-recovery.md`)
- [ ] 해제 후 **다시 완전 잠금을 걸어** 인계 상태로 되돌린다.

### 자동 검증(🖥️)은 어디서 보나요?

이 저장소를 GitHub에 push하면 **Actions → verify** 워크플로가 에뮬레이터에서 자동 실행됩니다.

- **screenshots** 아티팩트: 위 화면들의 실제 캡처 PNG + 한 장으로 모은 `contact-sheet.png` (폰으로 바로 확인 가능).
- **instrumented-test-report**: 화면 전환·PIN·터치 차단막 등 동작 테스트 결과.
- **kiosk-lock** 잡 로그 + **kiosk-logcat**: 완전 잠금 (1)~(6) 검증 결과.

에뮬레이터에는 계정이 없어 device owner를 걸 수 있으므로 (1)~(4)와 해제까지 자동 확인됩니다.
하지만 **삼성 실기기의 One UI 동작(7번)과 물리 버튼·전원·재부팅 체감(6번의 📱)** 은 반드시 현장에서 사람이 확인해야 합니다.

# NOWFLIX 키오스크 운영 가이드

태블릿을 다시 설치하지 않고, **관리자 웹**에서 내용을 바꾸는 방법입니다.
재생목록 교체 · 파트 추가 · 복귀 시간/PIN 변경 등 일상 운영은 전부 웹에서 합니다.

---

## 1. 관리자 웹 접속과 로그인

- 주소: **https://nowflix-admin.vercel.app**
  (PC·휴대폰 브라우저 모두 됩니다. 태블릿 관리자 화면의 QR을 찍어도 열립니다.)
- 로그인: **비밀번호 하나만** 입력합니다.
  - 최초 기본 비밀번호: **`nowflix2026`**
  - ⚠️ 처음 로그인하면 "기본 비밀번호를 바꾸라"는 안내 배너가 뜹니다.
    **설정 화면에서 반드시 새 비밀번호로 변경**하세요.
  - 비밀번호를 5번 틀리면 60초 동안 로그인이 잠깁니다(1분 뒤 자동 해제).

로그인하면 위쪽에 **파트관리 · 설정 · 상태** 세 개의 메뉴가 있습니다.

---

## 2. 재생목록(플레이리스트) 링크 바꾸기

각 "파트"는 유튜브 **재생목록** 하나와 연결돼 있습니다. 재생목록을 바꾸면
그 파트를 눌렀을 때 나오는 영상 목록이 통째로 바뀝니다.

1. **파트관리** 메뉴로 들어갑니다.
2. 바꿀 파트의 **수정** 을 누릅니다.
3. **재생목록 URL** 칸에 유튜브 재생목록 주소를 붙여 넣습니다.
   - 예: `https://www.youtube.com/playlist?list=PLxxxxxxxx`
   - 주소에서 `list=` 뒤의 값(재생목록 ID)만 자동으로 뽑아 저장합니다.
   - 저장할 때 그 재생목록이 실제로 존재하는지 유튜브에 확인하므로,
     **비공개/삭제된 재생목록**은 저장되지 않습니다.
4. **저장** 을 누릅니다.

> 재생목록은 **공개** 또는 **일부 공개(링크가 있는 사람만)** 여야 태블릿에서 영상이 보입니다.
> **상태** 메뉴에서 파트별 영상 개수와 비공개/삭제 경고를 확인할 수 있습니다.

---

## 3. 새 파트 추가하기

1. **파트관리 → "파트 추가"** 를 누릅니다.
2. **파트 이름**, **재생목록 URL**, **포스터 이미지**를 입력합니다.
3. **저장** 하면 목록 맨 뒤에 새 파트가 생깁니다.
   위·아래 화살표로 순서를 바꾸고, 노출 토글로 잠시 숨길 수도 있습니다.

### 포스터 이미지 규칙 (중요)
- **세로로 긴 4:5 비율** 이미지를 넣으세요. (예: 가로 720 × 세로 900 픽셀)
  메인 화면 카드가 세로 포스터 모양이라, 4:5가 아니면 위아래가 잘리거나 여백이 생깁니다.
- 형식은 **JPG 또는 PNG**, 용량 **5MB 이하**.
- 업로드하면 서버가 자동으로 세로 900픽셀 기준으로 크기를 맞춰 저장합니다.
- 포스터를 넣지 않으면 앱에 기본 이미지가 표시됩니다.

> 파트를 **삭제**할 때는 실수 방지를 위해 파트 이름을 직접 입력해 확인합니다.
> 삭제하면 업로드했던 포스터 이미지도 함께 지워집니다.

---

## 4. 복귀 시간과 PIN 바꾸기

**설정** 메뉴에서 바꿉니다.

- **메인 복귀 시간**: 손님이 아무 조작도 하지 않을 때 몇 초 뒤 메인 화면으로 돌아갈지.
  - 범위: **30초 ~ 600초**(10분). 기본값 120초.
- **앱 관리자 PIN**: 태블릿에서 관리자 화면에 들어갈 때 쓰는 **6자리 숫자**.
  - 초기값: **739104**. 병원에서 **꼭 새 번호로 변경**하세요.
  - 태블릿에서는 화면 **오른쪽 위 모서리를 3초간 길게** 누르면 PIN 입력창이 뜹니다.
- **헤더 문구**: 메인 화면 상단 문구("오늘 대한민국의 TOP 콘텐츠" 등).
- **웹 로그인 비밀번호**: 이 관리자 웹의 로그인 비밀번호(2번 항목의 그 비밀번호).

각 항목을 바꾸고 **저장**을 누르면 됩니다.

---

## 5. 바뀐 내용이 태블릿에 반영되는 시간

- 태블릿은 **30분마다 한 번** 관리자 웹의 설정을 스스로 다시 받아옵니다.
  → 그냥 두면 **최대 30분 안에** 자동으로 반영됩니다.
- 반영 전까지는 태블릿에 마지막으로 받은 내용이 계속 보입니다(인터넷이 잠깐 끊겨도 안전).

### 태블릿 앞에서 즉시 반영시키기
30분을 기다리지 않고 지금 바로 반영하고 싶을 때:

1. 태블릿 화면 **오른쪽 위 모서리를 3초간 길게** 누릅니다.
2. **관리자 PIN**(기본 739104, 변경했다면 새 번호)을 입력합니다.
3. 관리자 화면의 **"설정 새로고침"** 버튼을 누릅니다.
   → 방금 웹에서 바꾼 내용(파트/재생목록/복귀시간/PIN/헤더)이 즉시 반영됩니다.
4. **"닫기"** 를 눌러 키오스크로 돌아갑니다.

> 관리자 화면에서는 현재 복귀 시간·파트 수·마지막 설정 수신 시각도 확인할 수 있습니다.
> 잠금을 완전히 풀어야 할 때는 같은 화면의 **"키오스크 모드 완전 해제"** 를 사용합니다(인계문서 참고).
